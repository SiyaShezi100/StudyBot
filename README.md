# Dynacademy: AI-Powered Education & Career Guidance Platform

## 📌 Overview
Dynacademy is an AI-driven platform designed to assist learners in making informed educational and career decisions. It provides personalized recommendations, study support tools, and career guidance using modern web technologies and artificial intelligence.

## 🚀 Features
- AI Career Guidance System
- APS Score Calculator
- University & TVET Matching
- AI Study Assistant (summaries, quizzes, tutoring)
- Bursary Recommendation System
- Student Wellness Support
- AI Chatbot for real-time assistance
- Interactive dashboards and analytics

## 🛠️ Technologies Used
- React + Vite
- Tailwind CSS
- JavaScript / TypeScript
- Firebase / Supabase
- OpenAI API
- Chart.js / Recharts

## 🔍 Problem Statement
Many learners lack access to personalized career guidance, study support, and bursary information, leading to poor academic and career decisions.

## 💡 Solution
Dynacademy provides an all-in-one intelligent platform that uses AI to analyze learner data and deliver personalized recommendations for education and career pathways.

## 📈 Outcomes
- Improved learner access to career guidance
- Increased awareness of bursaries and study opportunities
- Better academic support through AI tools
- Enhanced career decision-making
